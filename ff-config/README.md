# FlashForge shipped printer configuration

These files are taken verbatim from the `klipper/config/` directory of the
FlashForge update package (`software-1.9.8`, identical in `software-1.9.7`).
The updater copies them to `/usr/data/config/` on the printer, where
`printer.cfg` includes `printer.base.cfg`.

Kept here so that changes FlashForge makes to them show up in the diff of the
next imported update package.
